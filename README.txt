カキツ、また / テキスト入力メモ

本文：
作品IDと同じ名前のTXTを texts/ に置きます。
例）texts/001.txt

チャット：
［CHAT-left］
ここから左側の吹き出し
［/CHAT］

［CHAT-right］
ここから右側の吹き出し
［REACTION：♡］
［/CHAT］

左右は自動交互ではなく、TXT側で毎回指定できます。
同じsideを連続して使うこともできます。

画像：
［IMAGE：001.jpg］

画像は images/ に置きます。
例）images/001.jpg

改ページ：
─── pagebreak ───

「」で始まる通常の会話文は、通常本文のままです。


038「川へと沈んだ先で」分岐：
038本編の末尾に次の1行を書くと、クリックできる分岐リンクになります。
［BRANCH］川へと沈んだ先で［/BRANCH］

texts/038.txt = 038本編
texts/038-happy.txt = ハッピーエンド本文
texts/038-true.txt = トゥルーエンド本文
works/038.html = 038本編ページ
works/038-branch.html = エンド選択画面
works/038-happy.html = ハッピーエンドページ
works/038-true.html = トゥルーエンドページ

各エンド末尾の「違う終わりを見に行く」は、もう一方のエンドへ移動します。
038の分岐移動は、通常より長く余韻を残してからページ遷移します。

v61 追加修正：墓場の作品リンクは works/ID.html を優先し、古い本文ページが root に残っている場合も自動でそちらを探します。


【アクセスカウンター】
トップページに「あなたは○○人目のお客様です。」を追加しています。
CounterAPI の無料公開カウンターを使い、トップページが読み込まれたときにカウントを1つ増やします。
GitHub Pages 側で追加設定は不要です。
※これは厳密な「ユニークな人間の人数」ではなく、CounterAPI の訪問カウントです。再訪や同一人物の複数回アクセスを完全に1人として判定するものではありません。

・ヘッダーに東城会代目会長カウンターを表示。
